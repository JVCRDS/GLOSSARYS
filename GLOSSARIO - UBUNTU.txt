Atalhos;

Crtl + Alt + D = terminal

Window + D = Area de trabalho

Comandos terminal:

whoami - usuário loggado;
~ - diretório padrão;
$ - modo user;
ls - lista o tudo que esta dentro do diretório atual;
ls -l - estrutura de permissões;
ls -A - arquivos ocultos;
clear - limpa terminal;
cd - vai para o diretório especificado;
(cd ~) OR (cd ..) - volta o diretório anterior;
mkdir {$NOME_PASTA} - cria uma pasta (OBS: cada espaço no nome irá criar uma pasta diferente);
rmdir {$NOME_PASTA} - deleta pastas (OBS: se as pastas não estiverem vazias não serão deletadas);
touch {$NOME_ARQUIVO} - cria um arquivo na pasta;
cat {$NOME_ARQUIVO} - informa o que esta escrito dentro do arquivo;
rm -r '{$NOME_PASTA}' - deleta pastas que possuem conteudo dentro e consequentemente esse conteudo;
sudo - utiliza permissões de root;
sudo apt update - verifica as atualzações dos pacotes presentes no sistema;
apt list --upgradable - visualiza especificamente os pacotes que possuem atualizações dentro do sistema;
Shift + Crtl + C/Shift + Crtl + V - copia e cola do terminal;
man apt - manual;
apt --help - comandos mais utilizados;
remove - remove pacotes;
reinstall - reinstala pacotes;
search - acha pacotes baseado no nome;
tail - vizualizar as ultimas linhas de uma arquivo de texto
tail -($QUANTIDADE_LINHAS) - pode ser usado dessa forma para mostrar uma quantidade especifica (ex: tail -20)
| grep - usado para fazer um filtro em um arquivo de texto (obs: deve ser usando com pipe) (ex: tail -20 syslog | grep failed , mostra as ultimas 20 linhas do arquivo de log do sistema que falharam.
journalctl - mostra os logs do sistema
journalctl -f - mostra os logs do sistema em tempo real
cat - mostra o conteudo de um arquivo de texto sem abrir o editor (ex:cat /etc/hostname)
